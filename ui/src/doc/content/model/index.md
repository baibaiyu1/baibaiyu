# 模型供应商管理

模型供应商是智能体的"推理引擎"，负责管理不同 AI 服务提供商的连接信息和认证配置。平台通过统一的供应商抽象层，支持接入多种主流大模型服务，并对每个供应商下的模型提供完整的生命周期管理与连接性检测能力。

## 功能概述

- 支持 4 种供应商类型：DashScope、OpenAI、Anthropic、Ollama
- 每个供应商下可配置多个模型，以**卡片网格**形式展示
- 支持两种认证方式：直接配置 `API Key`、`环境变量`引用
- 模型具备**六态连接检测**系统：停用 / 待检测 / 检测中 / 已连接 / 检测失败
- 支持模型类型：文本、图像、音频、视频
- 模型支持流式输出和深度思考模式
- 供应商下的模型可独立管理，支持启用/禁用、测试连接

## 核心概念

### 供应商类型

| 类型 | 说明 | 默认 Base URL |
|------|------|---------------|
| **DashScope** | 阿里云百炼平台 | `https://dashscope.aliyuncs.com` |
| **OpenAI** | OpenAI 官方 API | `https://api.openai.com` |
| **Anthropic** | Anthropic Claude API | `https://api.anthropic.com` |
| **Ollama** | 本地 Ollama 服务 | `http://localhost:11434` |

### 认证方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **直接配置（CONFIG）** | 在平台上直接填写 API Key，系统加密存储 | 快速配置，开发调试 |
| **环境变量（ENV）** | 填写环境变量名，运行时从部署环境读取 | 更安全，适合生产环境 |

### 模型配置属性

每个供应商下可配置多个模型，每个模型包含以下属性：

| 属性 | 说明 | 示例 |
|------|------|------|
| 模型名称 | 卡片展示名称 | `GPT-4o` |
| 模型编号 | API 调用标识符 | `gpt-4o`、`qwen-max` |
| 请求协议 | OpenAI 类型供应商选择 Chat Completions 或 Responses | 存量默认 Chat Completions |
| 模型类型 | 文本/图像/音频/视频，支持多选 | `CHAT`、`IMAGE` |
| 是否支持流式 | 是否支持流式输出响应 | 是/否 |
| 默认推理设置 | 推理模式、供应商支持的强度或预算、思考内容展示 | 模型默认 / 开启 / 关闭 |
| 上下文窗口 | 最大上下文 Token 数 | `128000` |
| 最大输出 | 单次对话最大输出 Token 数 | `4096` |
| 温度 | 生成随机性参数（0~2），越高越随机 | `0.7` |
| Top-P | 核采样参数（0~1） | `0.9` |
| Top-K | Top-K 采样参数 | `50` |
| 重复惩罚 | 重复内容惩罚系数 | `1.0` |
| 随机种子 | 可复现生成的种子值 | `42` |

### 使用 Responses 协议

在 OpenAI 类型供应商下编辑模型，把“请求协议”选择为 **Responses**，保存后执行“测试连接”。供应商必须提供 `/responses` 接口；Base URL 填接口前缀，例如 `https://api.openai.com/v1`。主模型、备用模型和摘要模型分别使用各自配置的协议。

Responses 支持流式文本、原生工具调用、结构化输出和推理内容回放。“最大输出 Token”映射为 `max_output_tokens`；推理强度按模型支持范围选择。默认关闭“发送温度与 Top P”，支持这两个参数的模型可主动开启。Top K、重复惩罚和随机种子不会发送到 Responses。

扩展配置支持固定请求头，以及 `reasoning.context`、`max_tool_calls`、`service_tier`、`prompt_cache_key`、`prompt_cache_options` 和 `safety_identifier`。推理开关、强度、预算和摘要请求统一通过“默认推理设置”管理；新配置中出现重复的原始推理参数会被拒绝。不支持额外查询参数；不认识的参数会明确报错。

系统自行管理会话历史，固定 `store=false`，禁止配置 `previous_response_id`，避免把其他会话的供应商状态接入当前对话。切换协议后需重新测试连接；原有模型不会自动切换。

OpenAI Responses 自动请求并保存供应商返回的加密推理内容；DeepSeek Responses 使用其返回的原始推理内容回放，供工具调用和多轮对话继续使用。旧 Chat 历史中只有文字的推理摘要仍可查看，但不会伪装成原生推理状态传给 Responses；普通回答及工具调用历史继续使用。

### 默认推理设置

推理模式和思考内容展示分别控制：**开启推理**决定请求模型推理，**展示思考内容**决定是否在对话中显示供应商返回的文字或摘要。选择“使用供应商默认”时不指定推理开关与强度，采用供应商默认行为；关闭推理后不能再设置强度或预算。固定推理模型不提供关闭选项。

系统按供应商、模型编号和协议识别能力。OpenAI 兼容代理使用自定义模型别名时，可选择实际的“推理兼容类型”。未知模型只提供默认模式与展示设置，不能用未经识别的开关制造已生效的假象。

对支持强度选择的模型，“开启推理”且强度为“自动”时发送 `high`，确保开启指令生效；“使用供应商默认”则不发送强度覆盖。

| 兼容类型 | 推理设置 |
| --- | --- |
| OpenAI 推理模型 | 按模型支持范围选择强度；Responses 展示供应商返回的推理摘要 |
| DeepSeek | 可切换模型支持 `low`、`high`、`max`；最高档为 `max`，旧 `xhigh` 实际等同于 `high` |
| Qwen | 使用思考开关和可选 Token 预算 |
| Anthropic | 使用思考开关和 Token 预算；开启时默认 1024，预算必须小于最大输出 Token |
| Gemini | 使用思考预算，固定推理模型不能关闭 |
| Ollama | 使用 `think` 开关，所选本地模型须支持推理 |

保存前会检查能力与预算限制，连通性检测使用同一套推理参数。旧配置仍按原来实际发送的参数读取；旧版 OpenAI 页面中未生效的“思考”开关不会被解释成新的关闭指令。重新保存时改用统一配置。

DeepSeek 推理模式不支持强制工具调用。开启推理或使用供应商默认时，智能体的“必须使用”按“自动”执行；“指定工具”只向模型提供所选工具，由模型决定是否调用。系统保留推理设置和工具权限限制。确实需要强制调用时，请使用支持关闭推理的模型并明确关闭推理；固定推理模型使用自动策略。

模型页设置是共享默认值。需要让某个智能体独立调整而不影响其他智能体时，在 [智能体设置](#/agent) 中开启“独立推理配置”。

## 模型卡片界面

重构后的模型管理采用**全屏卡片式布局**，替代了原有的表格列表形式。

### 卡片结构

每张卡片包含以下区域：

| 区域 | 内容 | 说明 |
|------|------|------|
| **头像区** | 模型图标 + 角标 | 根据连接状态变换头像色彩和角标 |
| **标题行** | 模型名称 | 可点击编辑，悬浮展示模型编号；超长自动省略 |
| **操作菜单** | 三点下拉菜单 | 测试连接 / 编辑 / 启用禁用 / 删除 |
| **描述区** | 模型描述 | 最多两行，超出省略 |
| **参数行** | Context / Tokens / T | 展示上下文窗口、最大输出、温度参数 |
| **标签区** | 流式/思考 + 模型类型 | 左侧显示流式/思考状态，右侧显示模型类型 |

### 连接状态六态系统

每张卡片左上角的头像及右下角角标实时反映模型连接状态，共六种状态：

| 状态 | 头像背景色 | 图标色 | 角标 | 说明 |
|------|-----------|--------|------|------|
| **已停用** | 灰 `#e7e7e7` | 灰 `#757575` | 无 | 模型已被禁用 |
| **待检测** | 黄 `#fff8e1` | 橙 `#ffa726` | 黄色叹号 ⚠ | 尚未进行连接测试 |
| **检测中** | 蓝 `#e3f2fd` | 蓝 `#42a5f5` | 无（loading 旋转） | 连接测试正在进行 |
| **已连接** | 绿 `#e8f5e9` | 绿 `#52c41a` | 绿色对号 ✓ | 连接测试通过 |
| **检测失败** | 红 `#ffebee` | 红 `#ef5350` | 红色叉号 ✗ | 连接测试失败，悬浮查看失败原因 |

> **提示**：鼠标悬浮在头像上可以查看当前状态的详细说明；检测失败时会显示服务端返回的具体错误信息。

### 工具栏

页面顶部工具栏采用**吸顶设计**（滚动时固定在顶部），包含：

- **新增模型** — 打开模型配置表单
- **搜索框** — 按模型名称搜索，支持回车触发

搜索为精确匹配，结果替换当前展示的模型列表。

## 操作指南

### 创建供应商

1. 在模型供应商管理页面点击 **添加模型供应商** 卡片
2. 填写表单：
   - **类型**：选择供应商类型（选择后自动填充默认 Base URL）
   - **名称**：供应商名称
   - **描述**：供应商说明
   - **Base URL**：API 地址
   - **认证方式**：直接配置或环境变量
   - **API Key / 环境变量名**：根据认证方式填写
3. 点击确认提交

### 打开模型管理

在供应商卡片右上角菜单点击 **配置模型**，弹出全屏模型管理窗口，展示该供应商下所有模型卡片。

### 新增模型

1. 点击顶部工具栏的 **新增模型** 按钮
2. 填写模型配置表单（名称、编号、类型、参数等）
3. 点击确认提交后，卡片列表自动刷新

### 编辑模型

1. 点击模型卡片标题，或在右侧下拉菜单中选择 **编辑**
2. 修改模型配置
3. 点击确认提交

### 测试连接

1. 在模型卡片右上角菜单中点击 **测试连接**
2. 头像区立即变为蓝色 loading 态
3. 测试完成后卡片列表自动刷新，头像和角标更新为最新状态
4. 测试失败时，鼠标悬浮头像可查看具体错误信息

### 启用/禁用模型

在卡片右上角菜单中选择 **启用** 或 **禁用**：

- 禁用的模型头像变为灰色，角标消失
- 当前被智能体引用的模型禁用时，弹出二次确认并提示影响的智能体列表

### 删除模型

在卡片右上角菜单中选择 **删除**：

- 被智能体引用的模型删除时，弹出二次确认并列出引用智能体
- 删除后卡片列表自动刷新

:::warning
删除或修改被智能体使用的模型时，关联智能体将自动重新注册。
:::

### 查看供应商详情

点击供应商卡片右上角菜单 → **查看**，查看供应商完整信息，详情弹窗展示以下字段：

| 字段 | 说明 |
|------|------|
| **供应商类型** | DashScope / OpenAI / Anthropic / Ollama |
| **名称** | 供应商名称 |
| **描述** | 供应商说明 |
| **Base URL** | API 服务地址 |
| **认证类型** | 直接配置（CONFIG）或环境变量（ENV） |
| **API 密钥** | 以掩码形式展示（如 `********`） |
| **环境变量名** | 当认证类型为 ENV 时展示 |
| **是否启用** | 是 / 否 |
| **创建时间** | 供应商创建时间 |
| **更新时间** | 最近修改时间 |

### 删除供应商

点击供应商卡片右上角菜单 → **删除**。

- 若供应商下存在关联模型，系统提示「请先删除模型配置」，不允许直接删除供应商
- 若无关联模型，弹出常规删除确认框
- 删除操作不可恢复

:::warning
删除供应商前必须先删除其下的所有模型配置。如果模型正在被智能体使用，需先在智能体中解除模型关联，然后删除模型，最后才能删除供应商。
:::

### 搜索模型

在顶部工具栏搜索框中输入模型名称，回车后按名称精确匹配筛选。清空搜索框后列表恢复全部展示。

## 在智能体中使用

在智能体配置的「模型与提示词」步骤中：

1. 选择供应商（按类型分类展示）
2. 选择该供应商下的模型
3. 可选配置模型参数覆盖（温度、Top-P 等）

## 常见问题

### 如何接入 Ollama 本地模型？

1. 创建类型为 `Ollama` 的供应商
2. Base URL 填写 Ollama 服务地址（默认 `http://localhost:11434`）
3. 认证方式选择"直接配置"，API Key 可留空或填写任意值
4. 在模型管理中添加本地已下载的模型编号
5. 通过「测试连接」验证连通性

### 如何接入兼容 OpenAI 协议的第三方服务？

1. 创建类型为 `OpenAI` 的供应商
2. 修改 Base URL 为第三方服务地址
3. 填写对应的 API Key
4. 通过「测试连接」验证连通性

### 环境变量认证如何使用？

1. 认证方式选择"环境变量"
2. 填写环境变量名（如 `OPENAI_API_KEY`）
3. 在部署环境中设置对应的环境变量值
4. 系统运行时自动从环境变量读取 API Key

### 连接测试失败怎么办？

1. 鼠标悬浮在模型卡片的头像上查看具体错误信息
2. 常见原因：API Key 无效、Base URL 不可达、模型编号不存在
3. 请检查供应商的 Base URL 和认证配置是否正确
4. 修正后重新执行「测试连接」

### 为什么不能删除供应商？

- 若供应商下存在模型配置，系统提示「请先删除模型配置」
- 必须先删除供应商下的所有模型，然后才能删除供应商
- 如果模型被智能体使用，需先在智能体配置中解除模型关联

### 如何选择合适的模型参数？

- **温度（temperature）**：0~2，越高越随机。创意写作建议 0.8~1.2，精确任务建议 0~0.3
- **Top-P**：0~1，核采样阈值。配合温度使用，通常设为 0.9
- **上下文窗口**：根据对话长度选择，长对话场景选择大窗口模型
- **最大输出**：根据回复长度需求设置，避免截断

### 禁用供应商会影响其下的模型吗？

- 禁用供应商时，若其下存在关联模型，系统会弹出二次确认
- 确认禁用后，供应商下的所有模型将无法被智能体使用
- 建议先确认无智能体使用其下的模型，再执行禁用
