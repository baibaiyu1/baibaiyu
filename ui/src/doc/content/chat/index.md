# 对话界面

对话界面是与智能体交互的核心入口，提供流式对话、文件上传、工具调用确认、记忆控制等能力，帮助用户高效地与智能体进行多轮交互。

## 功能概述

- 支持流式对话，实时查看智能体的回复过程
- 支持多会话管理，包括新建、切换、重命名、置顶、删除
- 支持文件上传和预览，文件类型受智能体配置限制
- 按智能体设置自动应用对话记忆，保持多轮对话上下文连贯
- 支持工具调用过程展示，以及需要确认的工具调用审批
- 工具、MCP 和知识库返回的图片直接显示在本轮对话中，并作为模型分析的视觉输入
- 知识库回答在相关段落末尾显示引用角标，文末文档卡片使用对应编号，可展开查看原文
- 支持工作空间面板（需智能体配置代码执行环境）
- 会话文件管理可按本人、负责部门或管理员范围查看；跨用户会话只读
- 响应式布局，适配桌面端和移动端

## 界面布局

对话界面采用三栏布局结构：

| 区域 | 说明 | 是否必须 |
|------|------|----------|
| **左侧边栏** | 会话列表管理区域，包含置顶会话和历史记录 | 是 |
| **中间主区域** | 消息展示与输入区域，包含欢迎页、消息列表、输入框 | 是 |
| **右侧工作空间** | 代码执行工作空间面板（需智能体配置代码执行环境） | 否 |

## 操作指南

### 开启新对话

1. 点击左侧边栏顶部的 **开启新对话** 按钮
2. 进入欢迎页，输入框中输入消息
3. 发送第一条消息后，系统以消息内容生成会话标题；尚未创建会话时会自动创建

智能体配置了代码执行环境且尚未选中会话时，欢迎页显示 **开始对话** 按钮；点击后创建或进入待用的新会话，并立即展开消息输入框。进入已有的空会话时，也会直接显示输入框。

智能体配置了推荐提问时，问题只在欢迎页中间的标题和介绍区域显示，点击可直接发送。发送第一条消息后不再展示，后续清空输入框也不会重新出现；开启新的空对话时恢复。正式对话与工作台预览使用相同规则，推荐问题可在智能体的“功能增强”中维护。

:::tip
发送第一条消息时，系统自动以消息前 50 个字符作为会话标题。你也可以在后续操作中重命名会话。
:::

### 发送消息

在输入框中输入消息后，可通过以下方式发送：

| 操作方式 | 说明 |
|----------|------|
| **Enter** | 直接发送消息（仅桌面端） |
| **Shift + Enter** | 输入换行（仅桌面端） |
| **发送按钮** | 点击输入框右下角箭头按钮发送（桌面端和移动端通用） |

:::tip
移动端不响应 Enter 键发送，请使用发送按钮，避免虚拟键盘误触。
:::

从点击推荐提问、按 Enter 或点击发送按钮开始，到会话创建和消息保存完成，系统会暂时禁用重复发送；网络较慢或刷新登录状态期间同样生效。智能体开始回复后，具备“运行中补充要求”权限的账号可以继续输入下一轮消息并排队。

通过局域网 HTTP 地址访问时，也可正常发送和排队消息；网络失败后重试同一条待发送消息不会重复入队。

### 思考内容展示

在 **Agent 设置 → 推理设置** 配置“展示思考内容”，正式对话、工作台预览和历史记录共用此设置。关闭后也会隐藏子智能体卡片中的思考轨迹；新运行不再输出或写入可见聊天记录的思考文字，但保留模型续跑所需的内部推理状态。记忆压缩的状态提示继续显示。

Chat Completions 和 Responses 都展示供应商实际返回的思考文字或摘要。OpenAI Responses 需由系统显式请求摘要；仅提高推理强度并不保证供应商返回可展示内容。DeepSeek Responses 返回的原始推理文字会按顺序展示，最终事件不会重复追加已显示的文字。推理模式与强度的含义见 [模型设置](#/model)。

### 中止生成

在智能体回复过程中，发送按钮会变为中止按钮（方形图标），点击即可中止当前生成。

中止后，已生成的部分内容会自动保存为一条助手消息。

### 运行中插队

任务运行中，直接在输入框发送消息，消息会默认等待当前任务完成。需要立即调整当前任务时，点击该消息右侧的 **插队**，例如“优先分析最近一个月的数据”。插队仅支持不带附件且不超过 4000 字的消息，每轮最多 50 条；超过长度时可先编辑，附件消息保留等待发送。角色需具备“运行中补充要求”权限，且只能操作本人的正式会话。

插队成功后，消息从待发送列表移入 **插队记录**，不会再次作为下一轮执行。插队沿用当前任务的记忆和计划设置。记录入口显示在输入框上方，点击可查看当前任务或全部记录及待生效数量。转换失败时，消息仍保留待发送；重复点击或网络重试不会重复投递。

要求会按接收顺序加入下一次模型推理。模型正在输出或工具正在执行时，需等到下一次推理才会生效；如果任务直接结束，则显示未应用。已经执行的操作不会撤回。

| 状态 | 含义 |
| --- | --- |
| 等待生效 | 已持久保存，等待下一次推理 |
| 正在加入推理 | 正在交接到模型输入 |
| 已加入推理 | 已进入一次模型调用的输入，不代表模型已经完成处理 |
| 未应用 | 运行结束、停止或等待审批时，尚未应用的要求被取消 |
| 已过期 | 待处理要求超过 24 小时，未应用 |
| 状态未确认 | 交接时发生中断，系统无法确认是否已调用模型；不会自动重放 |

刷新或重回会话后会补查最近 100 条补充要求及其状态。会话清空、删除时一并清理。游客分享、密钥调用、预览和他人的会话暂不开放此入口。多节点部署须将请求路由到活动运行所在节点；其他节点可以读取历史状态，但不能接收该运行的新要求。

### 运行中发送与下一轮队列

任务运行时，仍可正常输入并按 Enter 或点击发送箭头，默认等待当前任务结束后按顺序执行，支持附件，无需选择发送目标。消息在服务端接收后立即显示为紧贴输入框上沿的消息条，每条右侧提供 **插队**、编辑和删除操作。右下角共用一个按钮：运行中输入框为空时显示停止方块，有文字或附件时显示发送箭头；上传中或正在提交时不能重复发送。关闭网页后，服务端仍会继续执行。此能力需要“运行中补充要求”权限，仅限本人的正式会话。

编辑时可原地修改文字，点击 **保存** 或按 Ctrl/⌘ + Enter 提交，按 Esc 取消修改；附件和计划模式选择会保留。已经开始执行的消息不能再编辑、删除或插队。每会话最多排队 20 条，每条最多 16000 字，等待超过 24 小时会过期。执行时自动应用智能体当前的记忆、任务清单和工具调用展示设置，并重新校验当前账号、智能体和资源权限。权限失效或执行失败会暂停队列。已执行的消息进入正常聊天记录，输入框上沿只展示尚未发送的消息。

审批期间队列等待当前任务完成审批续跑，此时不能插队。点击停止会停止当前任务并暂停队列，未开始的消息仍保留，可删除或点击 **继续发送**。进程中断后已开始的消息标为中断，系统不会重试；恢复后只继续未执行的消息。清空或删除会话前需停止当前任务，队列随会话清理。

### 返回会话与断线恢复

切换页面或会话后，智能体继续在后台运行。重新打开运行中的会话时，系统按顺序补回当前任务的输出，再接收后续回复；长任务的输出超过内存事件窗口也可以恢复。回放只恢复展示，不会重新发送问题或执行工具。

如果运行事件记录已被清理或不可用，系统会自动补查已保存的聊天记录。任务仍在运行时持续更新，结束后再次补查最终记录及待确认工具，无需手动刷新。尚未保存的片段以服务端后续落库的记录为准；更早的消息可向上滚动加载。运行进程异常退出时，已开始的工具不会自动重放。

### 计划模式

在 **Agent 设置 → 高级配置** 开启 **显示计划模式入口** 后，登录账号使用自定义智能体、角色具备“运行中补充要求”权限时，输入框工具栏会显示带方案图标的 **计划模式** 按钮。存量智能体未配置该项时保持显示。选中后以蓝色和勾选标记提示状态，再次点击可取消下一轮的计划模式。选中后发送需求，智能体先只读调查，保存完整方案，再请求批准。入口显示设置与任务清单开关独立，无需修改部署配置或重启。

方案阶段允许读取已授权的附件、技能资料和工作区文件，允许编写方案及更新任务清单。写文件、Shell、动态代码、工作流、MCP 和子智能体委派在批准前被执行层拦截。未知工具不会因名称或远端只读提示被放行。

输入框上方的 **执行方案** 展示当前版本、内容和审批状态；点击 **在工作区预览方案** 可在既有文件预览器打开 `.plans/PLAN.md`。检查后点击工具审批的 **批准方案并执行**，智能体才会进入执行阶段；点击 **拒绝方案** 则保持只读并调整方案。

批准只对应服务端保存的方案版本与文件内容。重新保存方案、手动修改或删除方案文件后，旧批准失效；旧审批应先拒绝，再由智能体重新保存和提交。取消下一轮“计划模式”、在智能体设置中隐藏入口或关闭记忆，都不会解除已经生效的只读状态；隐藏入口后已有方案仍可查看和审批。刷新、重回会话及 Runtime 重启后仍可恢复方案与待审批工具。

“计划模式”可随下一轮排队保存。游客、密钥调用、预览及他人的会话不提供此入口。清空对话记录或删除会话时，方案文件与批准状态一并清理；仅清空消息会清理批准状态，工作区文件沿用工作区的清理操作，留下的旧方案文件不能自动获得批准。

### 实际模型用量

在 **Agent 设置 → 高级配置** 开启 **显示实际模型用量** 后，输入框上方的 **实际模型用量** 直接显示最近一轮的输入 Token、输出 Token 和模型调用数；有尚未完成或未返回用量的调用时，标注“已知小计”及未知调用数。该配置默认开启，关闭后隐藏对话中的入口并停止页面查询，服务端继续记录用量；重新开启可查看已有记录。

运行中自动更新，结束后补查最终记录，刷新会话后恢复服务端保存的用量。入口独立于运行中补充要求、记忆和模型容错开关；开启展示且登录账号具备“查看智能体”权限时可查看，归档会话同样遵循该展示配置。模型重试、备用模型与摘要模型也统一在 [Agent 设置](#/agent) 配置。

点击用量入口可打开明细面板。顶部展示最近任务的状态、输入/输出 Token、调用数与耗时；**任务汇总** 展示最近 20 轮，点击 **查看调用** 可直接定位该任务的明细。

**调用记录** 分页展示最近 200 条记录，可搜索模型、任务标识或错误类型，并按任务、调用类型和状态筛选；表格区分主模型、子智能体、摘要压缩、重试与模型切换，展示每次调用的真实用量。失败时显示错误类型，悬停可查看错误阶段。窄屏可横向滚动表格。运行中自动更新，查询失败可点击刷新重试。刷新会话后会从服务端恢复；会话清空或删除时同时清理。

这里的 token 来自供应商响应，与工具栏的上下文占用估算分开。流式累计用量每次调用只记最后一份快照，推理 token 通常包含在输出 token 中，不再相加。供应商未返回用量或调用尚未完成时显示未知；有未知调用时，已知 token 小计不是完整账单。调用记录保留最近 200 条，任务汇总最近 20 轮；按账号/租户/智能体汇总可由 `/runtime/agui/telemetry/summary` 查询。

观测自动记录，查询角色需具备“查看智能体”权限且有权查看该会话。系统不在观测记录中保存提示词、工具参数、文件正文或异常消息。进程异常退出时可能保留未结束记录，不能据此承诺活动任务恢复。

### 上传文件

1. 点击输入框工具栏中的 **附件** 按钮（回形针图标）
2. 选择一个或多个文件
3. 文件会先显示为"上传中"状态，上传完成后显示文件名
4. 可点击文件项进行预览（支持图片等媒体类型）
5. 点击文件项右侧的 **x** 按钮可移除已上传的文件

:::warning
文件类型受智能体配置限制，仅允许上传智能体配置中允许的文件类型。如果上传了不允许的文件类型，系统会提示警告并跳过该文件。
:::

### 工具栏功能

输入框下方工具栏提供以下功能按钮：

| 按钮 | 说明 | 启用条件 |
|------|------|----------|
| **计划模式** (方案图标) | 为下一轮选择先生成方案、批准后执行 | 智能体开启“显示计划模式入口”，本人正式会话且具有对应权限 |
| **附件** (回形针图标) | 上传文件附件 | 智能体需配置允许的文件类型 |
| **发送/中止** (箭头/方块图标) | 发送消息或中止生成 | - |

:::tip
- 记忆、任务清单和工具调用展示统一在 **Agent 设置 → 高级配置** 修改，对话自动应用，不再提供单独的记忆或工具展示按钮
- 工具调用详情关闭时，图片、文件产物和工具审批入口仍可正常使用
:::

## 会话管理

### 会话列表

左侧边栏展示当前账号在该智能体下的会话，分为两个区域：

| 区域 | 说明 |
|------|------|
| **置顶** | 已置顶的会话，最多占侧边栏 50% 高度，超出可滚动 |
| **历史记录** | 未置顶的会话，支持滚动加载更多 |

### 侧边栏折叠

- 点击侧边栏顶部的 **折叠** 按钮，可收起侧边栏
- 折叠后仅显示图标按钮，点击 **展开** 按钮可恢复
- 侧边栏的折叠状态会自动持久化

### 切换会话

点击会话列表中的会话项即可切换到该会话，加载其历史消息。

:::warning
智能体正在回复时无法切换会话，需先等待回复完成或中止生成。
:::

### 会话操作

点击会话项右侧的 **更多** 按钮（三个点），可执行以下操作：

| 操作 | 说明 |
|------|------|
| **重命名** | 修改会话标题，在弹窗中输入新标题后点击确定 |
| **置顶** | 将会话固定到置顶区域，方便快速访问 |
| **取消置顶** | 取消固定，会话回到历史记录区域 |
| **删除** | 删除会话及其中所有消息，删除后无法恢复 |

:::warning
删除会话是不可逆操作，删除后所有消息将无法恢复，请谨慎操作。
:::

### 一键清空对话记录

侧边栏「开启新对话」右侧的 **清空** 按钮（垃圾桶图标）可一次性删除当前智能体的**全部**对话记录：

| 项目 | 说明 |
|------|------|
| **删除范围** | 仅当前登录用户在该智能体下的会话，不影响其他账号、其他智能体的会话 |
| **删除内容** | 会话本身、全部消息（含归档分表中的消息）、消息分支、子智能体轨迹、会话工作空间文件 |
| **运行中的会话** | 自动先调用「停止」打断 Agent，再执行删除 |
| **影响面** | 删除后会话列表与消息均不可恢复，界面会回到欢迎页 |

:::warning
该操作不可逆。确认弹窗会显示将删除的会话条数，以及其中有多少条正在运行，请确认后再执行。
:::

### 加载更多

历史记录区域支持滚动加载：滚动到列表底部时自动加载下一页会话，加载完成时显示"已经到底了"提示。

## 消息展示

### 用户消息

用户发送的消息显示在对话区域的右侧，包含：

- **文件附件**：如有上传文件，在消息气泡中展示文件列表，点击可预览
- **文本内容**：消息的文字内容

### 助手消息

智能体的回复显示在对话区域的左侧，支持 Markdown 渲染，包括：

- 代码块语法高亮
- 表格、列表等富文本格式
- 数学公式（如果智能体返回了公式内容）

回复完成后，正文会保留在当前会话中，思考过程单独展示，无需切换会话重新加载。

同一轮中的思考、工具调用和中间文本紧凑排列。「复制」、版本切换和「重新生成」集中在该轮最终回复下方，悬停或聚焦时显示；中间步骤不重复显示这些操作。运行期间不显示当前轮的回复操作，历史回复的重新生成与版本切换暂时禁用。

### 工具调用

开启工具详情后，可查看内置工具、自定义工具和 MCP 工具的调用进度。需要用户审批的调用会单独显示确认入口。

#### 调用状态

| 状态 | 说明 |
|------|------|
| **调用中** | 显示"正在执行 [工具名]"，带加载动画和脉冲圆点指示器 |
| **需要确认** | 显示工具名称、参数展开/折叠按钮，以及"允许"和"禁止"按钮 |
| **已完成** | 调用结果以结构化消息形式保存在对话历史中 |
| **失败或中止** | 查看错误或中止原因；不会自动变成待确认调用 |

#### 工具返回的图片

知识库查询期间显示 **正在查询知识库** 和动态省略号，自动检索与思考后的按需检索均适用，关闭工具调用详情仍显示。收到查询结果（包括无结果或失败）、运行结束或中断后，等待提示会收起；工具参数发送完毕不代表查询已经完成。

知识库查询和回答生成期间，不展示候选图片、文档卡片或引用角标；文字分段输出的间隙也不会提前展示。整轮回答完成后，只在正文明确引用的位置显示知识库图片，未使用的候选图片不单独展示；文末只显示正文实际引用的文档。旧回答没有有效段落引用标记时，不展示检索文档卡片。

回答使用资料的段落或列表项末尾显示数字角标，点击角标可定位并展开文末同编号文档卡片。卡片默认只显示文件名和知识库，展开后查看路径和本次返回的原文片段；同一轮重复引用同一文档共用编号，不同知识库的同名文件分别编号。图谱实体和关系按各自的来源文件生成引用，不能借用其他向量片段的文档来源。仅参与图谱检索而未返回原文片段的来源会说明原因。关闭工具详情不会隐藏最终引用，正式会话重新打开后仍可查看。

查询包含产品型号时，知识图谱图片按图片描述或型号与图片的直接图谱关系筛选。同一文档里的标志、其他型号和其他产品图片不会因文档命中就自动展示；无法核实对应关系时可只返回文字。

工具、MCP、生成文件和用户附件中的图片共用图片卡片与预览器。正文通过 Markdown 明确引用当前轮已产生的图片时，图片显示在引用所在的位置。知识库图片遵循上述完成后展示规则；其他工具没有被正文引用的图片紧跟产生它的工具步骤，即使关闭工具调用过程或折叠工具详情也能看到。同一张图片被正文引用后，不会再在工具步骤旁重复显示。代码示例中的图片语法不算实际引用。

图片使用紧凑缩略图，相邻图片自动并排，单张图片不再占满正文宽度。每个工具步骤默认显示前 6 张，可展开全部；点击后使用工作空间预览器查看完整图片、放大、缩小、旋转、下载，或切换上一张、下一张。工具提供的有效图片名称会保留，包括中文、英文、产品型号和数字；没有名称时统一使用「图片」，不附加编号，展示名和下载名保留对应的图片格式后缀。正文中的远程图片也使用相同卡片和预览操作，但可用性取决于原地址；它们不会自动保存成工具图片副本。

回复持续输出时，已显示的图片不会随文字更新重复加载。其他工具的图片在正文完成引用时，从工具步骤移到引用处；其后继续输出文字会保留缩略图和已打开的预览。正式会话、工作台预览和只读历史遵循相同的知识库图片与引用展示规则；升级前缺少工具关联信息的文件按时间和来源工具尽量定位。

对话正文使用更宽的阅读区域，输入框与正文对齐，并随工作空间或预览面板宽度自适应。新内容输出和图片加载时，页面在底部自动跟随；上滑阅读后暂停跟随，可点击“回到最新回复”继续查看。复制回答时，引用转为可读编号并附带对应文档名称。

图片的实际内容会参与工具执行后的模型推理，智能体可以结合截图、图表等内容继续回答。智能体使用的模型需要支持图片输入；希望在后续轮次继续询问同一张图片时，应开启记忆。正式会话中的图片保留为不可变副本，重新打开会话和查看历史时仍可展示，原始图片地址失效或原文件被覆盖不会改变已保存的图片。编排页的临时调试会话也支持图片展示和预览，只允许该临时会话的归属人读取，调试消息仍仅保留在当前面板中。

当前支持 PNG、JPEG、GIF、WebP、BMP；单张图片上限 10 MB，单次工具返回最多处理 20 张，并受工作空间容量限制。图片内容无效、下载失败或超过限制时显示原因，其余文字结果和图片继续处理。升级前未保存的工具图片无法从旧文字历史自动恢复。

#### 工具调用确认

关联确认钩子且工具标记为「需要确认」时，智能体会在执行前暂停：

- 点击 **允许**：客户端提交允许决策，后端使用已保存的调用参数执行工具，再让智能体继续处理
- 点击 **禁止**：本次调用不执行，该工具在当前轮次内禁止再次调用；智能体根据拒绝信息调整后续行为，下轮重新应用工具配置
- 点击 **展开参数** / **折叠参数**：查看或隐藏工具调用的参数详情（JSON 格式）

:::tip
- 审批独立于「显示工具调用过程」和记忆开关，关闭详情或记忆仍可审批
- 只有服务端保存的待确认记录才能续跑；工具报错、超时或网络断开不会自动变成待审批
- 无参数工具的 `{}` 是合法输入，无需补填参数；待确认参数由服务端校验和保存
:::

正式会话刷新页面或 runtime 重启后，可重新获取仍然有效的待确认记录并继续审批。恢复的是已保存的暂停状态，已经执行中的外部工具不保证自动续跑。工作台临时预览的审批只在当前运行节点保存一小时，重启、切换节点或过期后需重新开始。

#### 工具调用详情

已完成的工具调用以结构化消息形式保存在对话历史中（需开启"显示工具调用过程"），点击可展开/折叠查看：

- **工具名称**：被调用的工具名称
- **调用耗时**：工具执行所花费的时间（毫秒）
- **调用参数**：发送给工具的参数（JSON 格式），无参数时不显示
- **调用结果**：工具返回的执行结果

:::tip
- 工具调用详情默认处于折叠状态，点击"工具调用"标题可展开查看完整内容
- 关闭详情会隐藏普通工具过程；工具返回的图片仍单独保存和展示，审批入口也仍可用
:::

### 错误消息

当智能体运行出错时，错误信息会以红色文字显示在对话区域中。

## 工作空间面板

智能体实际生成或修改的文件会跟随产生它的工具步骤显示。图片优先显示在正文的引用位置，未被引用时显示在该步骤旁；其他文件显示文件卡片。重新打开会话和查看只读历史时使用相同布局，点击卡片复用工作空间预览器。

文件通知短暂断开不会影响已保存的文件。回复结束、从后台返回页面、网络或 WebSocket 恢复后，页面会自动补查当前会话的文件；补查失败时保留已显示的卡片，切换会话时不会混入上一会话的迟到结果。

新生成的文档、图片、表格等交付文件会要求智能体优先采用与内容相关的中文名称，例如「对话内容整理.docx」「设备截图.png」。用户明确指定文件名时遵循用户要求；已有文件、上传文件和第三方资源沿用原路径。实际命名仍由生成文件的模型或工具执行。

DOC、DOCX 文件可通过产物卡片或工作空间下载，当前不支持 Word 在线预览。

当智能体配置了代码执行环境时，对话界面右上角会出现 **工作空间** 按钮（文件夹图标）：

- 点击按钮可展开/收起工作空间面板
- 面板从右侧滑出，与对话区域并排显示
- 进入欢迎页（新建对话）时，工作空间面板会自动关闭

## 智能体能力开关

对话界面中的部分功能受智能体配置影响，只有智能体启用了对应能力，对应功能才可用：

| 功能 | 智能体配置项 | 说明 |
|------|-------------|------|
| 记忆持久化 | 开启记忆 | 开启后对话自动读取和保存上下文 |
| 任务清单 | 启用任务清单 | 开启后智能体可拆解任务并更新进度 |
| 工具调用历史 | 显示工具调用历史 | 开启后自动展示工具的调用名、耗时、参数和结果 |
| 计划模式入口 | 显示计划模式入口 | 控制输入区按钮是否显示，不影响已有方案的查看和审批 |
| 文件上传 | 允许上传文件类型 | 配置后附件按钮可用 |
| 工作空间 | 执行环境配置 | 配置后工作空间面板入口可用 |

智能体设置中的记忆开关影响下次运行时读取和保存的上下文，页面中的已有聊天记录仍可查看。关闭记忆不会删除原持久历史，本轮内容也不会覆盖原历史；重新开启后继续使用原上下文。浏览器旧偏好和接口中的兼容开关字段不能覆盖智能体设置。

审批续跑沿用暂停时的上下文。如果一轮在开启记忆时暂停，随后关闭记忆，该轮续跑仍保存到原持久状态，下轮才改用临时上下文。清空消息或删除会话时，主智能体和子智能体的状态同步清理。

## 外部访问模式

游客可通过专用分享链接在外部浏览器中打开对话页面：

- `#/chat/{agentId}` 是需要登录和资源使用权的内部入口
- 智能体发布后，由管理员在设计面板 → API 页签开启游客访问并获取 `#/communication/{chatKey}` 链接
- 游客只能使用分享链接绑定的智能体；关闭外放或刷新链接后旧链接失效
- 如需 API 对接，可在 API 页签中查看详细的接口文档和鉴权方式

## 常见问题

### 发送消息没有反应？

- 检查输入框是否为空（纯空格不算有效内容）
- 检查是否有文件正在上传中（上传中的文件会阻止发送）
- 检查智能体是否正在回复中（需等待或中止后才能发送新消息）

### 文件上传失败？

- 检查文件类型是否在智能体允许的范围内
- 检查网络连接是否正常
- 文件上传失败后，该文件会自动从附件列表中移除

### 如何开启对话记忆或工具调用展示？

- 进入 **Agent 设置 → 高级配置**，开启“开启记忆”或“显示工具调用历史”
- 保存后后续对话自动应用，对话工具栏不再提供这两个开关

### 工作空间按钮不可见？

- 需在智能体的高级设置中配置"执行环境配置"
- 只有配置了代码执行环境的智能体才会显示工作空间入口
- 在欢迎页（无会话）时，工作空间入口也会隐藏

### 工具调用一直显示"正在调用"？

- 可能是工具执行耗时较长，请耐心等待
- 生成文档等长时间任务遇到短暂网络断开时，对话会自动恢复当前运行
- 如长时间无响应，可点击中止按钮终止当前生成
- 运行已结束时先查看错误提示，刷新后以服务端运行状态为准；仅服务端明确返回待确认记录时才能审批

### 工具调用的"允许"和"禁止"有什么区别？

- **允许**：后端使用保存的参数执行待确认工具，并恢复智能体运行
- **禁止**：工具不执行，本轮内禁止再次调用该工具
- 审批不依赖工具详情开关；配置要求见 [工具管理](#/tool)

### 移动端侧边栏如何关闭？

- 点击侧边栏外的遮罩层区域即可关闭
- 选择会话后侧边栏也会自动关闭

### 如何在外部浏览器中打开对话页面？

- 智能体完成发布后，由管理员在设计面板 → API 页签开启游客访问并复制专用链接
- 普通 `#/chat/{agentId}` 是内部入口，外部游客应使用 `#/communication/{chatKey}`；关闭游客访问或刷新链接后旧链接失效

### 如何管理会话工作空间文件？

- 在「设置 → 存储管理 → 会话文件」按会话查看容量、目录和文件预览
- 本人的未归档会话可上传、编辑、删除或清空文件；部门负责人可只读负责部门及子部门的会话文件；管理员可管理全部会话文件
- 游客会话由具备游客会话管理权限的管理员单独清理，清理时会同时删除消息和工作空间文件

### 如何使用本地语音对话？

当前版本暂时隐藏语音对话入口，待体验完善后再开放。以下说明供恢复开放后参考。

- 部署并配置本地语音服务后，拥有“对话补充”权限的登录账号可在本人未归档会话中点击“语音对话”；空会话会自动创建正式会话。
- 浏览器需要允许麦克风，并通过 `localhost`、`127.0.0.1` 或 HTTPS 访问。显示“开启声音”时，点击后允许播放助手声音。
- 显示“等待语音助手就绪”时，正在等待语音服务完成初始化；进入“正在聆听”后再说话。45 秒仍未就绪会提示重新启动语音服务，并自动断开、释放麦克风。只启动 LiveKit 容器不能完成识别和回复，还需在配套语音项目执行 `scripts/start.ps1`；电脑重启后也需执行。
- 可以随时开口插话，也可以点“停止播报”。这只停止声音，已接收的业务任务继续执行；需要终止任务时仍使用对话输入区的中止按钮。
- 语音中的新任务进入现有消息队列，补充要求在当前任务下一推理点应用。运行中的工具不会因为插话自动取消，方案和工具审批仍在界面完成。
- 正式答复边生成边按短句播报，首句生成后即开始合成，播放时继续准备后续句子；不再等整轮完成后额外生成口语摘要。资料引用、图片和文件继续显示在现有聊天与工作空间中，闲聊字幕不另写入正式消息历史。
- 播报跳过推理过程、工具参数、代码块、图片和链接地址；链接保留说明文字。长回答播报约 2400 字后提示查看完整内容。插话、停止播报或中止任务会丢弃尚未播放的句子，语音重连与聊天历史回放不会重播旧内容。
- 静音暂停麦克风输入；结束语音、切换会话或离开页面会释放麦克风。重连不会自动重发没有确认接收的语音要求。
- 识别、合成与插话检测可全部在本机运行，不需要购买语音 API；理解与生成答复仍使用智能体绑定的模型并计入实际模型用量。
- 游客链接、SK 调用和归档会话不提供这个语音入口。初始本机部署不支持直接从其他电脑或手机连接。

### 如何对接对话 API？

- 进入智能体设计面板 → API 页签，查看完整的接口文档
- 重点关注：智能体对话接口、鉴权方式（SkKey / ChatKey）、会话管理接口
- API 页签中提供了详细的调用示例
