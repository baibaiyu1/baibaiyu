# 智能体管理

智能体将模型、提示词、工具、技能、MCP 和知识库组合成可运行的业务助手。本页介绍创建、配置、调试与发布；实际聊天、工具审批、图片和文件操作见 [对话界面](#/chat)。

推荐顺序：先配置可用的模型，创建智能体并填写任务目标，再按需关联资源，在工作台预览中验证，最后启用并提交发布审批。

## 功能概述

- 支持两种智能体类型：自定义（CUSTOM）和 A2A（Agent-to-Agent）
- 创建弹窗只填写基本信息，编号自动生成，创建后进入设计页配置模型、工具和知识库等能力
- A2A 智能体支持 WellKnown 和 Nacos 两种发现模式
- 提供配置面板，包含编辑、定时任务、架构图、API 文档、日志、统计分析
- 支持启用/禁用、搜索筛选、标签分类
- 支持私有、组织公开，以及指定账号或部门授权；发布与游客外放分别控制
- 支持架构可视化图，直观展示智能体关联的资源
- 支持多轮记忆、历史摘要压缩、任务清单和工具审批

## 核心概念

### 智能体类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| **自定义（CUSTOM）** | 本地 ReAct 智能体，可完整配置模型、工具、知识库等 | 需要精细控制智能体行为的场景 |
| **A2A** | 远程智能体，通过 A2A 协议连接外部 Agent | 已有外部 Agent 服务，需通过 A2A 协议集成 |

### 访问范围与发布

个人空间新建智能体默认私有，部门空间新建的资产默认供部门及下级成员使用。归属人或有维护资格的账号可扩大共享范围，也可在卡片的「授权访问」中多选账号或部门，授予仅查看或查看并使用权限。部门授权覆盖该部门及所有下级部门，成员变动后实时生效；指定账号授权不因账号换部门而失效。两类授权都不授予编辑权。共享后归属人可继续维护个人资产。个人资源的负责人查看权不会自动变成使用权或编辑权；部门资产由所属部门管理范围内的负责人或指定维护人维护，操作仍需对应权限。管理员可查看并管理全部资源。

「发布」决定其他成员能否运行智能体；访问范围决定谁能发现和使用它。普通成员运行时必须同时满足资源使用权、已启用和已发布。配置或能力变更后需重新提交发布审批。

游客访问另由管理员在设计面板的 API 页签开启，并使用专用分享链接。关闭游客访问或刷新链接会使旧链接失效；发布状态和内部公开范围都不会自动开放游客访问。

### 工具选择策略

| 策略 | 说明 |
|------|------|
| **AUTO** | 自动选择 — 模型自行判断是否调用工具 |
| **NONE** | 禁止调用 — 不允许调用任何工具 |
| **REQUIRED** | 强制调用 — 必须调用至少一个工具 |
| **SPECIFIC** | 强制调用指定工具 — 必须调用指定的某个工具 |

DeepSeek 开启推理或使用供应商默认时，`REQUIRED` 按自动选择执行，`SPECIFIC` 仅提供所选工具并由模型决定是否调用；明确关闭推理后保留强制策略。兼容行为见 [模型设置](#/model)。

### A2A 发现模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **WELLKNOWN** | 通过 Well-Known 路径发现 Agent Card | 已知 Agent 的 Base URL 和 Card 路径 |
| **NACOS** | 通过 Nacos 注册中心发现 Agent | Agent 注册到 Nacos 服务 |

## 操作指南

### 创建自定义智能体

在智能体管理页面点击 **添加新智能体** 卡片 → 选择 **自定义** 类型，打开创建弹窗：

#### 填写基本信息

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| **名称** | 智能体名称 | 是 |
| **描述** | 智能体功能说明 | 是 |
| **标签** | 多个分类标签，用于分组管理 | 否 |

点击「添加标签」或「选择或管理标签」打开弹窗。弹窗每次从当前组织的标签表读取候选，可搜索并勾选多个标签；输入新名称后点击「新增」，新标签立即保存到标签表并选中。点击「确定」将选择应用到智能体表单，点击「取消」不改变智能体已选标签。已选标签旁的「×」只解除当前智能体的关联，保存智能体后生效。弹窗内标签右侧的删除按钮会删除标签表中的标签；仍有智能体使用该标签时，须先从相关智能体移除并保存，才能删除目录标签。新增到标签表的标签不随弹窗或智能体表单取消而删除。

点击 **创建并设计** 后，系统自动生成唯一编号并进入该智能体的设计页。新建智能体默认私有、停用且未发布，可在设计页补充模型与提示词、工具、知识库、MCP 等配置，保存并验证后再启用。编号可在 **Agent 设置 → 基础信息** 中查看和维护。

#### 设计页：模型与提示词

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| **模型配置** | 选择基础模型配置（从模型供应商管理中已配置的模型列表选择） | 是 |
| **模型参数覆盖** | 覆盖基础模型参数（如温度、Top-P 等），不填则使用模型默认值 | 否 |
| **独立推理配置** | 单独配置推理模式、强度或预算，以及思考内容展示 | 否（默认继承模型） |
| **提示词模板** | 下拉框始终显示，可搜索并选择各分类下已启用的模板，导入内容到当前智能体 | 否 |
| **跟随模板更新** | 开启后同步模板内容并设为只读；关闭后可独立编辑，不随模板变化 | 否 |
| **系统提示词** | 手动编写或在导入模板后继续修改任务指令 | 否 |

在 **Agent 设置 → 推理设置** 也可维护独立推理配置。关闭时跟随模型页的默认推理设置；开启时复制当前值并保存到本智能体，此后修改共享模型的默认推理设置不会改变该智能体。关闭独立配置会恢复继承。采样参数覆盖与推理覆盖分别保存，关闭其中一个不会清除另一个。

推理模式与展示互不替代：关闭“展示思考内容”仍可使用高强度推理；选择“关闭推理”后不能设置强度或预算。界面会显示当前生效值及其来源，具体能力与协议映射见 [模型供应商管理](#/model)。切换模型后如新模型不支持已保存的强度或预算，需先调整配置再保存。

智能体独立推理配置同时约束主模型和备用模型，保存与运行时都会校验兼容性；摘要模型和子智能体采用各自配置。模型的协议、连接地址及认证仍由模型页管理。旧智能体扩展参数中的推理配置会识别为独立配置，下一次保存时转为统一格式。

:::tip
不想跟随模板时，关闭「跟随模板更新」后仍可通过下拉框导入模板内容，再在编辑器中修改。选择其他模板会替换当前正文；清除模板选择会关闭跟随并保留当前正文。重新开启跟随后，会以模板最新内容替换正文，并恢复只读。
:::

#### 设计页：工具与能力

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| **钩子** | 关联钩子（Hook），在智能体执行前后触发自定义逻辑 | 否 |
| **工具选择策略** | AUTO / NONE / REQUIRED / SPECIFIC | 否（默认 AUTO） |
| **工具** | 关联工具（Tool），为智能体提供执行能力 | 否 |
| **指定工具名称** | 当策略为 SPECIFIC 时，指定必须调用的工具名称 | 条件必填 |
| **技能包** | 关联技能包（Skill），为智能体提供预置能力组合 | 否 |
| **执行环境配置** | 关联执行环境配置，允许智能体执行代码 | 否 |
| **敏感词配置** | 关联敏感词配置 | 否 |
| **启用敏感词过滤** | 是否启用敏感词检测与过滤 | 否 |

#### 设计页：知识库与 MCP

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| **知识库** | 关联知识库，为智能体提供专业知识检索能力 | 否 |
| **MCP 服务器** | 关联 MCP 服务器，扩展智能体的工具调用能力 | 否 |
| **子智能体** | 关联子智能体，实现多 Agent 协作 | 否 |

关联知识库后，**知识库调用策略** 卡片会汇总调用方式、知识图谱检索模式、Top K、超时和图片额度。点击 **配置策略**，先选择“速度优先（推荐）”“图谱增强”或“继承默认”，再按需调整常用设置。手动微调后标记为“自定义”，所有修改均在保存智能体后生效。

超时、并发和重试收在 **调用与等待预算**；图谱数量、Token 与重排收在 **知识图谱高级检索**；字符预算和图片数量收在 **证据与图片额度**。各分组收起时仍显示配置摘要，知识库默认值可单独展开查看。`naive / mix / local / global / hybrid` 均可选择，向量模式下收起不生效的图谱字段，切换模式保留已填参数。未覆盖检索参数继承各知识库，同一个知识库可供多个智能体使用不同策略。参数范围、推荐值和质量限制见[知识库调用策略](#/knowledge)。

:::warning
子智能体不能形成循环引用。每个子智能体拥有独立的会话上下文，并沿用主智能体的用户身份。需要用户确认或浏览器表单输入的操作应由主智能体发起；子智能体不等待此类交互。
:::

#### 设计页：高级设置

| 字段 | 说明 | 默认值 |
|------|------|--------|
| **模型容错与摘要模型** | 管理员配置主模型最大尝试次数（1～5 次）、备用模型与独立摘要模型 | 关闭自定义 |
| **启用任务清单** | 拆解任务并在对话中持续更新执行进度，原“计划能力” | 否 |
| **显示计划模式入口** | 在正式对话输入区显示计划模式按钮，选中后先生成方案、批准后执行；关闭不影响已有方案审批 | 是 |
| **最大迭代次数** | ReAct 循环的最大迭代次数 | 50 |
| **最大子任务数** | 任务清单中的最大子任务数 | 10 |
| **更新任务清单需确认** | 更新任务清单前等待用户确认；需同时启用记忆 | 否 |
| **显示工具调用历史** | 开启后对话自动展示调用详情，不影响审批或图片展示 | 否 |
| **显示实际模型用量** | 在有查看权限的正式对话中展示实际 Token 用量与调用明细；关闭后仍记录用量 | 是 |
| **开启记忆** | 开启后对话自动读取和保存会话上下文 | 是 |
| **启用记忆压缩** | 是否启用记忆压缩（长对话时自动压缩历史） | 否 |
| **记忆压缩配置** | 记忆压缩的参数配置 | - |
| **执行环境配置** | 开启工作空间，以及执行 Shell、读写文件的能力 | - |
| **Studio 配置** | 关联 Studio 画布配置 | - |

:::tip
- 需要记录多步骤执行进度时启用任务清单；最大迭代次数限制模型推理与工具调用的循环次数
- 需要连续追问时启用记忆；长对话接近模型上下文容量时再配置压缩
:::

### 模型容错与摘要模型

管理员可在 **Agent 设置 → 高级配置** 中开启 **模型容错与摘要模型**，分别保存最大尝试次数（包含首次，1～5 次）、备用模型和摘要模型。普通资源归属人可以保留已有配置，修改或清空需管理员；普通账号 Fork 的副本不继承此配置。关闭普通模型参数覆盖不影响这项配置。保存后新运行直接生效。

模型仅在首个响应前对限流、网络、超时和服务错误重试，最大次数耗尽后调用备用模型一次；已开始输出后不会重新生成或切换，工具操作不会因此重复执行。备用模型必须使用相同供应商类型、覆盖主模型输入类型，并有足够上下文和结构化能力；这些声明仍需配合供应商实际支持情况验证。鉴权和参数错误直接失败。

摘要模型只用于开启记忆压缩后的摘要调用，未选时使用主模型；上下文窗口需容纳待压缩历史。原有四项压缩参数继续有效，失败或未缩短时保留历史。可在 [实际模型用量](#/chat) 核对每次尝试使用的模型、用量和重试/切换次数；失败调用未返回用量时保持未知。

模型容错、摘要模型与“显示实际模型用量”均在 **Agent 设置 → 高级配置** 中维护，与记忆、任务清单等设置一同保存；取消设置弹窗不会修改原值。提示词区域只负责模型与提示词配置。

“显示实际模型用量”默认开启，已有智能体未配置该项时保持显示。关闭后，正式对话及归档会话隐藏用量入口并停止页面查询，服务端继续保存实际用量；重新开启即可查看已有记录。它独立于记忆、工具调用展示和模型容错开关，查询仍需“查看智能体”权限。

### 任务清单、计划模式、审批与记忆

启用任务清单后，智能体通过任务清单持续记录步骤和进度，任务状态包括「待处理」「进行中」「已完成」。每次更新提交完整清单，数量受最大子任务数限制；旧会话中的任务清单仍可查看。开启「更新任务清单需确认」后，清单更新会暂停等待用户决策。

“显示计划模式入口”单独控制正式对话中的按钮，默认显示。用户可为下一轮选择先调查、生成方案并批准后执行；它与任务清单独立。关闭入口不影响已有方案的查看、审批和只读限制。具体操作见 [对话界面](#/chat)。

记忆、任务清单和工具调用展示统一在智能体设置维护，正式对话和工作台预览自动使用已保存配置，不再从对话工具栏或浏览器偏好单独切换。

工具审批需要关联内置确认钩子，并将对应工具标为「需要确认」。它独立于工具详情显示和对话记忆开关；关闭详情仍会显示审批入口。允许或拒绝的操作和恢复方式见 [对话界面](#/chat)，配置方法见 [工具管理](#/tool)。

开启记忆时，智能体读取并保存当前会话上下文。关闭后，本轮使用独立临时上下文，不读取或覆盖已有持久历史；重新开启仍可使用原历史。清空或删除会话会同时清理主智能体与子智能体状态。若从持久状态暂停后再关闭记忆，本次审批续跑仍完成原状态保存，下轮才使用临时上下文。

### 记忆压缩

每次推理前达到 Token 或消息阈值时，将较早内容合并成摘要，保留最近消息，并避免拆开工具调用与结果。任务清单单独保存，摘要后仍可继续执行；页面中的聊天历史保持不变。

| 配置 | 作用 |
| --- | --- |
| **最大 Token 数** | 估算上下文预算，应结合模型容量设置 |
| **Token 比率** | 与最大 Token 数相乘，得到摘要触发阈值 |
| **消息阈值** | 历史消息达到该数量时触发摘要 |
| **保留最近消息数** | 最近消息原样保留，较早内容参与摘要 |

可通过「智能配置」生成方案，再根据对话长度调整。摘要会损失部分细节，并增加一次模型调用；没有可安全摘要的内容时跳过，摘要失败或未缩短上下文时保留原历史。

升级到 AgentScope 2.0 后，旧版的最小压缩 Token 阈值、最小连续工具消息数、大负载阈值、卸载预览长度和当前轮压缩比停止使用，现有配置请按上述四项重新确认。

需要固定 JSON 格式时，可在 [工作流](#/workflow) 的智能体节点配置结构化输出 Schema。普通聊天目前不应用旧的结构化输出提醒模式配置。

### 创建 A2A 智能体

在智能体管理页面点击 **添加新智能体** 卡片 → 选择 **A2A · WellKnown** 或 **A2A · Nacos**，打开基本信息弹窗。

#### 基本信息

与自定义智能体相同，只填写名称、描述和可选标签，编号由系统自动生成。点击 **创建并设计** 进入现有设计页，再完善所选协议的连接参数和增强配置。新建 A2A 智能体也默认停用，连接配置保存后再启用。

#### A2A 配置

**WellKnown 模式：**

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| **Agent 名称** | 远程 Agent 的名称标识 | 是 |
| **Base URL** | 远程 Agent 服务的 Base URL | 是 |
| **Agent Card 路径** | Agent Card 文件的相对路径（如 `/.well-known/agent.json`） | 是 |
| **认证头** | HTTP 请求的认证头信息（Key-Value 对，支持环境变量引用） | 否 |

**Nacos 模式：**

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| **Agent 名称** | 注册到 Nacos 的 Agent 名称 | 是 |
| **Nacos 属性** | Nacos 连接属性（Key-Value 对，支持环境变量引用） | 是 |

:::tip
认证头和 Nacos 属性中的值支持环境变量引用：开启「环境变量」开关后，值字段填写环境变量的 Key，运行时将自动从系统环境变量中获取实际值。这种方式避免了在配置中明文存储密钥等敏感信息。
:::

### 查看详情

点击卡片右上角菜单 → **查看**，查看智能体完整配置：

- 自定义智能体：展示基本信息、模型配置、关联资源数量等
- A2A 智能体：展示基本信息、A2A 连接配置、认证头信息等

### 设计面板

创建成功后自动进入工作台，也可点击卡片上的 **设计** 按钮再次进入。模型、提示词、能力和高级设置均在这里维护，配套面板提供以下功能：

| 页签 | 说明 | 可用类型 |
|------|------|----------|
| **配置** | 编辑智能体的完整配置（自定义 / A2A 各有专属编辑界面） | 自定义 + A2A |
| **定时** | 配置定时任务，让智能体定时自动执行 | 自定义 + A2A |
| **架构** | 查看智能体架构可视化图，直观展示关联的所有资源 | 仅自定义 |
| **API** | 查看智能体的 API 文档和调用方式 | 自定义 + A2A |
| **日志** | 查看智能体的对话历史日志 | 自定义 + A2A |
| **统计** | 查看智能体的使用统计和性能指标 | 自定义 + A2A |

工作台中的工具、技能包、工作流、知识库、MCP 服务和子智能体都可通过已选项旁的「×」解除关联，点击「保存更改」后生效。移除 MCP 时会同时移除它的工具暴露配置，保留的 MCP 配置不受影响；移除全部知识库会清空智能体的检索参数覆盖，再次添加时使用新知识库的默认参数。关闭模型参数覆盖或清空可选配置后，保存并重新打开仍保持关闭或清空状态。钩子的执行顺序也是配置的一部分，拖拽调整后需要保存。资源选择弹窗点击「取消」不改变当前配置。

各资源卡独立加载本类候选项，加载完成后更新已选资源数量与名称。

### 调试与发布

在工作台预览中发送测试问题，检查模型回答、工具结果、任务清单，以及图片和文件产物。预览用于验证当前配置；调试消息只保留在当前面板，临时会话不能替代正式聊天历史。

预览中待审批操作的归属只在当前运行节点保存一小时。运行节点重启、切换或临时状态过期后，需要重新开始调试。需要长期保留消息或检验重启后的审批恢复时，使用正式对话会话。

保存配置后启用智能体，并按页面提交发布审批；影响配置或能力的修改需要重新发布。组织公开、账号/部门授权和游客访问分别设置，发布不会自动改变这些访问范围。

### 启用/禁用智能体

- 通过卡片上的开关切换启用状态
- 禁用后智能体将从运行时注销，不再响应请求
- 启用后智能体将重新注册到运行时
- 若智能体正在被其他智能体引用，禁用时系统会弹出二次确认提示，显示引用的智能体名称

:::warning
如果智能体关联了定时任务，需先禁用定时任务才能禁用智能体。禁用被引用的智能体时，系统会显示「该智能体正在被 [xxx] 智能体引用，禁用后可能会影响上述智能体的正常使用」。
:::

### 访问对话

点击卡片上的 **访问对话** 按钮会打开内部对话页。`#/chat/{agentId}` 要求登录，并检查该账号的智能体使用权及发布状态。需要让游客使用时，由管理员开启游客访问后，从设计面板的 API 页签取得专用分享链接。

### 删除智能体

点击卡片右上角菜单 → **删除**：

- 若智能体正在被其他智能体引用，系统会弹出二次确认框，显示引用的智能体名称
- 若无引用，弹出常规删除确认框
- 删除操作不可恢复

:::warning
删除前需确保：
1. 智能体没有关联的定时任务（需先解绑定时任务）
2. 确认引用方不再需要该智能体（如有引用）
3. 删除后不可恢复，请谨慎操作
:::

## 配置说明

### 模型参数覆盖

模型参数覆盖允许在基础模型配置上调整参数，支持以下字段：

| 参数 | 说明 |
|------|------|
| temperature | 生成温度，控制随机性（0.0 ~ 2.0） |
| topP | 核采样概率阈值 |
| topK | Top-K 采样数量 |
| maxTokens | 最大生成 Token 数 |
| repeatPenalty | 重复惩罚系数 |
| seed | 随机种子 |

### 认证头配置（KvMap）

A2A 智能体的认证头和 Nacos 属性使用 KvMap 结构：

| 字段 | 说明 |
|------|------|
| **key** | 属性名 / Header 名 |
| **value** | 属性值 / Header 值（或环境变量 Key） |
| **evn** | 是否为环境变量引用 |

示例：
- 直接值：`key=Authorization`, `value=Bearer xxx`, `evn=false`
- 环境变量：`key=Authorization`, `value=API_AUTH_TOKEN`, `evn=true`（运行时从环境变量 `API_AUTH_TOKEN` 读取）

### 版本号

每个智能体都有一个版本号（如 `1.0.0`），用于跟踪配置变更。

## API 对接

在设计面板的 **API** 页签查看接口、鉴权方式和调用示例。内部对接使用授权的 SkKey；游客访问使用绑定单个智能体的 ChatKey。管理接口还会检查菜单权限与资源管理范围，资源查看授权不能用于修改配置。

多节点调用须使用部署方提供的统一入口，并传递与请求 `threadId` 相同的 `X-GMD-FAQ-Thread-Id`，让同一会话保持在相同运行节点。工具审批续跑只提交决策，工具参数以服务端保存的待确认记录为准。

## 常见问题

### 智能体无法启用？

- 检查是否已配置模型（模型配置为必填项）
- 检查关联的定时任务是否已禁用（需先禁用定时任务才能修改智能体）

### A2A 智能体连接失败？

- 检查 Base URL 是否正确可达
- 检查 Agent Card 路径是否正确
- 检查认证头配置是否正确
- 如果使用环境变量，确认系统环境变量已正确设置

### 工具未被调用？

- 检查工具选择策略是否为 NONE（禁止调用）
- 如果策略为 SPECIFIC，检查指定工具名称是否正确
- 检查工具是否已启用

### 智能体响应不符合预期？

- 调整系统提示词，使指令更加清晰明确
- 检查是否启用敏感词过滤，可能误过滤了内容
- 调整模型参数（如增大 temperature 增加创造性，降低 temperature 增加确定性）
- 检查关联的知识库检索是否返回了正确结果
- 检查工具选择策略是否合理，模型可能未选择正确的工具

### 如何分享智能体对话给他人使用？

- 组织成员先通过「组织公开」或「授权访问」取得使用权，再用内部对话入口
- 游客使用须先完成发布，再由管理员在智能体设计面板 → API 页签开启游客访问
- 从该页复制 `#/communication/{chatKey}` 分享链接；关闭游客访问或刷新链接可撤销访问

复制按钮支持局域网 HTTP 访问；浏览器限制自动复制时，可手动选择页面上的完整链接复制。

游客可通过对话使用智能体已绑定的工具和技能。分享页不加载工具和技能的配置列表，会话文件仍可正常引用。

### 删除智能体提示"请先解绑定时任务"？

- 进入设计面板 → 定时页签
- 禁用或删除关联的定时任务
- 然后重新执行删除操作
