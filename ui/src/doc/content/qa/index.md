# 常见问题 (Q&A)

本章节汇总了平台使用过程中的常见问题及解决方案，帮助您快速定位和解决问题。

## 一、智能体相关

### 1、智能体配置的 Skill 中包含脚本，为什么无法执行？

:::info 原因
智能体执行脚本需要执行环境配置。
:::


:::success 解决方案
进入 **智能体 → 设计 → 配置 → 高级设置**，配置「执行环境配置」
:::


### 2、给智能体配置了敏感词，为什么不生效？

:::info 原因
配置敏感词后还需要手动启用敏感词过滤功能。
:::

:::success 解决方案
进入 **智能体 → 设计 → 配置 → 工具与能力**，勾选「启用敏感词过滤」选项
:::

### 3、如何配置智能体执行工具时需要用户确认？

:::success 解决方案
1. **开启工具确认**：进入 **工具 → 编辑**，开启「是否需要确认」选项
2. **配置确认钩子**：进入 **智能体 → 设计 → 配置 → 工具与能力 → 钩子配置**，选择内置钩子中的 `IConfirmationHook`
3. **保存并重新进入对话**：用会触发该工具的问题验证审批入口
:::

:::warning 提醒
工具审批不依赖记忆或「显示工具调用过程」开关。允许、拒绝和恢复方式见 [对话界面](#/chat)。
:::


### 4、如何关闭对话过程中的工具调用历史？

:::success 解决方案
1. 进入 **智能体 → 设计 → Agent 设置 → 高级配置**，关闭「显示工具调用历史」选项并保存
2. 后续运行自动应用该配置；对话页不再提供单独的工具展示开关，已有调用记录仍可查看
:::


### 5、为什么多个 Agent 绑定同一 Studio 时，A 项目的消息出现在 B 项目中？

:::info 原因
AgentScope 中的 `StudioManager` 采用全局单例设计，其定位是调试智能体使用，不适合多个智能体同时开启。
:::

:::success 解决方案
智能体正式使用时，务必关闭 Studio 可视化调试功能，避免不同智能体之间的消息串扰
:::

### 6、如何停止智能体的定时任务？

:::success 解决方案
进入 **智能体 → 设计 → 定时**，在任务列表里关闭该行的「状态」开关即可暂停（任务配置保留，可随时重新启用）
:::

### 7、如何删除智能体的定时任务？

:::success 解决方案
进入 **智能体 → 设计 → 定时**，点任务行右侧操作列的「删除」图标，确认后即可彻底删除该任务
:::

## 二、MCP 相关

### 1、配置的 MCP 不可使用？

:::success 解决方案
1. 检查 MCP Key 是否正确。进入 MCP 配置页面，确认 API Key 或认证信息无误
2. 如果配置的是 STDIO 协议，检查本地运行环境是否正确：
   - 确认本地已安装 MCP 服务所需的运行时环境（如 Node.js、Python 等）
   - 确认 MCP 服务的启动命令和参数是否正确
   - 确认本地环境变量配置是否完整
:::

## 三、对话相关

### 1、与智能体对话时，为什么无法上传文件？

:::success 解决方案
1. **配置存储方案**：进入 **设置 → 存储管理 → 存储配置**，配置存储方案（推荐使用 `LOCAL` 本地存储，存储路径如 `E:\tmp\gmd-faq`）
2. **配置多模态模型**：选择一个支持多模态的模型（如 `qwen3.5-plus`），在模型配置中勾选对应的「模型类型」（支持多选，如 IMAGE）
3. **为智能体配置多模态模型**：编辑智能体，将模型配置替换为支持多模态的模型，保存后即可在对话中上传文件
:::

### 2、如何在外部浏览器中打开对话页面（无需登录）？

:::success 解决方案
先完成智能体发布，由管理员在 **智能体 → 设计 → API** 开启游客访问，再复制专用分享链接。普通 `#/chat/{agentId}` 链接需要登录和资源使用权。
:::

### 3、如何对接顶火智能体平台中对话界面相关的 API？

:::success 解决方案
进入 **智能体 → 设计 → API**，重点关注以下内容：

- **智能体对话接口**：发送消息、接收回复的核心接口
- **鉴权方式**：接口认证机制（如 SkKey、ChatKey 等）
- **会话管理接口**：创建、查询、删除会话等管理操作

详细的接口文档和调用示例可在 API 页面中查看。
:::

## 四、登录与账号

### 1、如何登录顶火智能体平台？

登录页采用居中的品牌标题与表单布局，输入管理员分配的账号或邮箱及密码后，点击 **登录**。勾选 **记住账号** 只记录账号，不保存密码。

平台不提供自助注册。如需开通账号或重置密码，请联系所在组织的管理员；管理员创建账号或重置密码后，首次登录需按提示修改密码。

## 五、系统设置

### 1、在哪里管理组织和用户？

进入 **设置 → 组织与成员**。左侧组织树就是组织架构本身：

- 每个组织节点右侧常显两个按钮：**新增下级**（在该组织下新建子部门）与**详情**（查看组织编码、负责人、成员数、联系人、描述等）；
- 组织详情里可继续**编辑资料**或**删除组织**（存在下级组织或已分配用户时不能删除）；
- 树顶部的 **+** 用来新增顶级组织，搜索框可按名称过滤；
- 点击任意组织节点，右侧账号列表就切换成该组织及其全部下级部门的成员，每行都会标出账号所属部门的完整路径；点「全部组织」查看全部账号。

账号的新增、组织归属、角色、密码与状态维护都在右侧列表完成：选中组织后可直接「添加成员」把已有账号加入本组织，或用「新增用户」创建全新账号。

### 2、在哪里维护菜单和按钮权限？

进入 **设置 → 菜单管理**。左侧菜单结构选择范围，右侧按目录、菜单和按钮权限分类显示数量；可搜索名称、权限字符或路径，并按启用状态筛选。未筛选时支持逐级展开、展开全部和收起全部；搜索或筛选后直接显示匹配节点及其所属路径。

点击菜单名称、整行或 **详情** 打开详情抽屉，可查看配置、复制权限字符，并搜索和维护该节点下的按钮权限。在左侧选定菜单后，**新增下级** 会自动带入上级菜单；新增、编辑与删除操作按对应权限显示。

新增和编辑表单按节点类型展示字段：目录用于归类，菜单可配置路由与组件，按钮权限只需维护名称、权限字符和启用状态等信息。按钮权限的权限字符必填；上级菜单不能选择按钮、自身或自己的下级节点。

### 3、能看到资源，为什么不能修改或运行？

菜单与按钮操作权限由角色绑定的菜单权限决定，身份名称不能代替操作授权。请管理员检查对应权限是否已分配。

智能体、工具、技能、知识库和 MCP 还受资源归属、可见范围与账号/部门授权约束。查看授权不授予编辑权；共享不改变维护资格，个人资产由归属人维护，部门资产由负责人或指定维护人维护，平台公共资产由管理员或指定维护人维护。普通成员运行智能体还需使用权，且智能体已启用、已发布。内部共享与游客访问分别设置，具体规则见 [智能体管理](#/agent)。



### 4、如何切换个人空间和部门空间？

在左侧导航顶部的「资源空间」中切换范围。智能体、工具、技能、知识库和 MCP 共用当前选择，进入其他资源页面时仍保持；收起侧栏后可点击空间图标切换。各资源页保留列表筛选和新建目标提示：

| 空间 | 展示资源 | 创建规则 |
| --- | --- | --- |
| 个人空间 | 归当前账号所有的个人资产 | 需要对应资源的新增或导入权限 |
| 部门空间 | 归所选部门所有的资产 | 本部门成员或该部门管理范围内的负责人可创建，仍需新增或导入权限 |
| 平台公共 | 平台统一维护的资产 | 仅管理员可创建；其他成员按可见范围浏览和使用 |
| 全部可访问 | 合并本人有权访问的各类资源 | 新建到个人空间，页面会显示目标空间 |

部门选择范围由服务端按当前成员和负责人关系计算。普通成员可进入本人所属部门，负责人可选择负责部门及下级部门，管理员可选择全部部门。**共享给我** 和 **我的收藏** 会在所选空间内继续筛选；跨部门授权的资源可在 **全部可访问** 中查找。智能体设计页的资源选择器仍展示全部可用依赖，不受列表空间筛选限制。

资源卡片在名称下方以图标和文字标明个人、部门或平台归属；已扩大共享的资源显示「已共享」，平台私有资源显示「访问受限」。悬停归属说明可查看默认访问范围。卡片底部的轻量标签展示类型、已设置的分类和发布状态，未设置分类时不显示占位标签。

切换空间只改变资源工作范围，账号所属组织、角色权限、对话历史和会话文件范围继续沿用原有规则。部门内部资源默认供所属部门及下级部门成员使用；私有个人资源仍允许管理范围内的负责人只读查看。扩大共享范围与发布智能体、游客访问分别设置。

### 5、如何移交资源或更换维护人？

在资源卡片菜单选择 **归属与移交**，选择个人、部门或平台归属，再指定归属账号、所属部门和可选维护人。确认后按新归属判断维护权限，已有主键、创建记录和单独访问授权保留；共享的部门范围按新归属重新计算。

个人资产由归属人或管理员移交；部门资产由负责该部门的负责人或管理员移交，指定维护人不能自行移交。非管理员不能把部门资产转成个人资产，也不能设为平台公共资产。部门资产维护人必须属于该部门或下级部门；不指定维护人时由负责人和管理员维护。

共享后的资源可由有资格的维护人直接更新，不需要先收回共享。已有资源保留原来的个人或平台归属，需要成为部门资产时再显式移交；账号调岗不会自动移动资产。部门仍有资产时必须先移交，才能删除部门。各操作同时要求对应资源的编辑、删除、启用等权限。
